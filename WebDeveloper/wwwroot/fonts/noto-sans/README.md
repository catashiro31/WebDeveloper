Noto Sans variable font (weight 100–900), distributed under the SIL Open Font License in OFL.txt.
Source: https://github.com/google/fonts/tree/main/ofl/notosans
Downloaded NotoSans[wdth,wght].ttf and losslessly encoded as WOFF2 using fontTools + Brotli.
No glyph subsetting: Vietnamese precomposed characters and combining marks are retained.
The application serves this file locally through css/typography.css; no font CDN is required.
